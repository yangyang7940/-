# 智能简历筛选与岗位匹配系统

专业综合实训项目，作者：赵子恒（计科中外1班）。系统使用 Python 在本地完成简历与岗位的可解释匹配，不需要联网、付费 API 或独立显卡。

## 一、项目功能

- 单份智能匹配：粘贴简历或读取 TXT/MD 文件，生成 0～100 分综合得分；
- 四维可解释评分：文本相似度、技能覆盖、经验匹配、学历匹配；
- 匹配依据展示：列出已匹配技能、待补充技能、亮点和复核要点；
- 批量候选人排名：对 18 份匿名测试简历统一评分；
- 结果导出：将单份匹配结果导出为 JSON；
- 隐私保护：所有计算均在本机完成，不上传简历。

## 二、运行环境

- Windows 10/11、macOS 或 Linux；
- Python 3.9 及以上版本；
- Chrome、Edge 或 Firefox 浏览器。

项目核心功能仅使用 Python 标准库，不需要额外安装第三方依赖。

## 三、快速运行

### Windows 图形方式

双击项目根目录中的 `启动系统.bat`。启动程序会自动寻找可用的 Python，并打开浏览器：

```text
http://127.0.0.1:8765
```

### 命令行方式

在项目目录中执行：

```bash
python app.py
```

若不希望自动打开浏览器：

```bash
python app.py --no-browser
```

停止系统时，在运行窗口按 `Ctrl+C`。

如果双击后未成功启动，新的启动窗口不会自动消失，而会显示错误信息并等待按键。常见处理方法：

1. 确认安装了 Python 3.9 或更高版本；
2. 安装 Python 时勾选 `Add Python to PATH`；
3. 若提示 8765 端口被占用，先关闭之前开启的系统窗口，再重新启动；
4. 仍不能运行时，保留启动窗口并截图错误内容。

## 四、演示操作建议

1. 在“单份智能匹配”中选择“Python数据分析师”；
2. 在匿名测试样例中选择“陈晨 · Python数据分析师”；
3. 点击“开始智能分析”，讲解综合分、四维分数和技能缺口；
4. 切换“候选人批量排名”，选择“Java后端工程师”并生成排名；
5. 切换“评分方法说明”，说明权重设计和公平使用边界。

`data/demo_resume.txt` 也可用于文件读取演示。

## 五、测试与评估

运行全部自动测试：

```bash
python -m unittest discover -s tests -v
```

运行标注测试集评估：

```bash
python evaluate.py
```

评估结果会写入 `docs/evaluation_results.json`。测试数据均为课程演示使用的虚构匿名数据，不对应真实个人。

## 七、评分规则

```text
综合得分 = 文本相似度 × 40%
         + 技能覆盖率 × 35%
         + 经验匹配度 × 15%
         + 学历匹配度 × 10%
```

- 80～100：高度匹配，建议优先进入面试；
- 65～79.9：较匹配，建议进入初筛；
- 50～64.9：可考虑，建议结合项目经历复核；
- 0～49.9：暂不匹配，建议保留人才库。

## 八、注意事项

- 系统定位为初筛辅助工具，不应替代人工面试和材料核验；
- 不应把性别、年龄、籍贯、照片等敏感属性加入评分；
- 技能词典和岗位权重可按真实业务场景调整；
